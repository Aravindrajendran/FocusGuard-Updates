# FocusGuard Updates

This public repository is the distribution channel for FocusGuard Android builds. The application source remains in the private `FocusGuard-Clean` repository.

## Update status

**Automatic publishing is not connected yet.** Do not install an APK from this repository until a release is published and its signing compatibility has been checked.

## Planned release files

- GitHub Releases: signed APK releases
- `latest.json`: version and download metadata for the in-app update checker

## Security

Never commit signing keys, passwords, access tokens, or private source code here. Release APKs must be signed with the same persistent Android signing key used for compatible in-place updates.
